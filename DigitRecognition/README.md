# DigitRecognition - iOS Приложение

iOS приложение для распознавания рукописных цифр с использованием нейронной сети.

## Описание

Приложение позволяет пользователю:
- Выбирать изображения из галереи
- Фотографировать цифры с камеры
- Отправлять изображения на сервер для распознавания
- Просматривать результаты с детальной статистикой

## Требования

- iOS 15.0+
- Xcode 14.0+
- Swift 5.7+

## Установка

1. Откройте проект в Xcode
2. Замените `YOUR_SERVER_IP` на IP-адрес вашего ноутбука в файле `APIClient.swift`
3. Соберите и запустите проект на устройстве или симуляторе

## Использование

### 1. Настройка сервера

Перед использованием приложения убедитесь, что:
- Python сервер запущен на вашем ноутбуке
- Устройство iOS и ноутбук находятся в одной сети
- Вы знаете IP-адрес ноутбука

### 2. Настройка приложения

1. Откройте файл `DigitRecognition/Services/APIClient.swift`
2. Замените `YOUR_SERVER_IP` на реальный IP-адрес вашего ноутбука:
```swift
self.baseURL = "http://192.168.1.100:5000"  // Пример
```

Или используйте поле ввода URL в приложении.

### 3. Запуск приложения

1. Запустите приложение на устройстве
2. Предоставьте разрешения на доступ к камере и фото (если требуется)
3. Выберите изображение из галереи или сфотографируйте цифру
4. Нажмите кнопку "Распознать"
5. Просмотрите результаты распознавания

## API Интеграция

Приложение взаимодействует с Python сервером через REST API:

### POST /predict

Отправляет изображение на сервер для распознавания.

**Запрос:**
- Content-Type: `multipart/form-data`
- Поле: `image` (PNG файл)

**Ответ:**
```json
{
  "success": true,
  "predictions": [0.01, 0.02, 0.85, 0.05, 0.02, 0.01, 0.01, 0.01, 0.01, 0.01],
  "predicted_class": 2,
  "confidence": 0.85
}
```

## Компоненты

### APIClient

Синглтон для выполнения HTTP запросов к серверу.

**Основные методы:**
- `checkHealth(completion:)` - Проверка работоспособности сервера
- `predictDigit(image:completion:)` - Распознавание цифры на изображении
- `updateServerURL(_:)` - Обновление URL сервера

### CameraService

Сервис для работы с камерой и галереей устройства.

**Основные методы:**
- `pickImage(from:completion:)` - Выбор изображения из галереи
- `captureImage(from:completion:)` - Съемка фото с камеры
- `checkCameraPermission(completion:)` - Проверка разрешений камеры
- `checkPhotoLibraryPermission(completion:)` - Проверка разрешений галереи

### MainView

Главный экран приложения с:
- Областью предпросмотра изображения
- Кнопками выбора источника изображения
- Кнопкой распознавания
- Полем ввода URL сервера

### ResultView

Экран отображения результатов с:
- Предсказанной цифрой
- Уверенностью модели
- Графиком распределения вероятностей

## Разрешения

Приложение требует следующие разрешения:
- Доступ к камере (`NSCameraUsageDescription`)
- Доступ к фото (`NSPhotoLibraryUsageDescription`)

Добавьте в `Info.plist`:
```xml
<key>NSCameraUsageDescription</key>
<string>Приложению нужен доступ к камере для фотографирования цифр</string>
<key>NSPhotoLibraryUsageDescription</key>
<string>Приложению нужен доступ к фото для выбора изображений</string>
```

## Настройка сети

### Для локального тестирования

1. Узнайте IP-адрес вашего ноутбука:
   - macOS: Системные настройки → Сеть
   - Linux: `ip addr show` или `ifconfig`
   - Windows: `ipconfig`

2. Убедитесь, что устройство и ноутбук в одной сети

3. Настройте брандмауэр для разрешения входящих подключений

### Для удаленного сервера

Если сервер развернут удаленно:
- Используйте публичный IP-адрес или доменное имя
- Настройте SSL сертификат для HTTPS
- Обновите URL в приложении

## Troubleshooting

### Не удается подключиться к серверу

1. Проверьте, что сервер запущен
2. Убедитесь, что IP-адрес правильный
3. Проверьте, что устройства в одной сети
4. Проверьте настройки брандмауэра

### Ошибка при отправке изображения

1. Проверьте формат изображения (PNG)
2. Убедитесь, что размер изображения не слишком большой
3. Проверьте логи сервера

### Нет доступа к камере/фото

1. Проверьте разрешения в настройках устройства
2. Убедитесь, что описания добавлены в Info.plist
3. Попробуйте переустановить приложение
