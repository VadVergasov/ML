# Сервер распознавания цифр

Flask-сервер для распознавания цифр на изображениях с использованием нейронной сети.

## Структура проекта

```
server/
├── app.py              # Flask-приложение
├── config.py           # Конфигурация
├── model_loader.py     # Загрузчик модели (Singleton)
├── image_processor.py  # Предобработка изображений
└── README.md           # Этот файл
```

## API Эндпоинты

### GET /health

Проверка работоспособности сервера и информации о модели.

**Ответ:**
```json
{
  "status": "healthy",
  "model": {
    "input_shape": ["None", "28", "28", "1"],
    "output_shape": ["None", "10"],
    "num_params": 12345,
    "model_path": "../2/numbers.h5"
  },
  "config": {
    "image_size": [28, 28],
    "image_channels": 1,
    "allowed_extensions": ["png", "jpg", "jpeg", "gif", "bmp", "tiff"]
  }
}
```

### POST /predict

Распознавание цифры на изображении.

**Запрос:**
- Content-Type: `multipart/form-data`
- Поле: `image` (файл изображения)

**Ответ:**
```json
{
  "success": true,
  "predictions": [0.01, 0.02, 0.85, 0.05, 0.02, 0.01, 0.01, 0.01, 0.01, 0.01],
  "predicted_class": 2,
  "confidence": 0.85
}
```

**Ошибки:**
- `400` — отсутствует файл, недопустимый формат, невалидное изображение
- `413` — файл слишком большой (максимум 16 MB)
- `500` — внутренняя ошибка сервера

## Примеры использования

### cURL

```bash
# Проверка здоровья
curl http://localhost:5000/health

# Распознавание цифры
curl -X POST \
  -F "image=@/path/to/image.png" \
  http://localhost:5000/predict
```

### Python

```python
import requests

# Проверка здоровья
response = requests.get("http://localhost:5000/health")
print(response.json())

# Распознавание цифры
with open("image.png", "rb") as f:
    response = requests.post(
        "http://localhost:5000/predict",
        files={"image": f}
    )
    result = response.json()
    print(f"Цифра: {result['predicted_class']}")
    print(f"Уверенность: {result['confidence']:.2%}")
```

## Модель

Модель обучена на датасете SVHN (Street View House Numbers):
- **Вход:** изображения 28×28 пикселей, grayscale
- **Выход:** вектор из 10 вероятностей (цифры 0-9)
- **Архитектура:** CNN с residual блоками

## Предобработка изображений

Сервер автоматически выполняет следующую предобработку:

1. Декодирование изображения из multipart/form-data
2. Конвертация в RGB (если необходимо)
3. Нормализация: деление на 255.0
4. Конвертация в grayscale (как при обучении)
5. Resize до 28×28 пикселей (как при обучении)

## Конфигурация

Параметры конфигурации находятся в [`config.py`](config.py):

| Параметр | Описание | Значение по умолчанию |
|----------|----------|----------------------|
| `MODEL_PATH` | Путь к файлу модели H5 | `../2/numbers.h5` |
| `HOST` | Хост сервера | `0.0.0.0` |
| `PORT` | Порт сервера | `5000` |
| `DEBUG` | Режим отладки | `False` |
| `IMAGE_SIZE` | Размер изображения | `(28, 28)` |
| `IMAGE_CHANNELS` | Количество каналов | `1` |
| `MAX_CONTENT_LENGTH` | Макс. размер файла | `16 MB` |

```bash

```

### Linux
```bash
ip addr show | grep "inet " | grep -v 127.0.0.1
```

### Windows
```cmd
ipconfig
```

Найдите IP-адрес в локальной сети (обычно начинается с `192.168.1.` или `10.0.0.`)

## Устранение проблем

### Ошибка: "Файл модели не найден"

Убедитесь, что файл модели существует:
```bash
ls -la ../2/numbers.h5
```

### Ошибка: "Address already in use"

Порт 5000 уже занят. Измените порт:
```bash
SERVER_PORT=8000 python app.py
```

### Ошибка: "Permission denied"

Убедитесь, что у вас есть права на чтение файла модели и запись в логи.

### Медленная загрузка модели

Модель загружается только один раз при старте сервера (Singleton). Если нужно перезагрузить модель, перезапустите сервер.

## Логирование

Сервер логирует все операции:
- Загрузка модели
- Запросы к API
- Ошибки и предупреждения

Логи выводятся в консоль.

## Производительность

- Время загрузки модели: ~2-5 секунд (один раз при старте)
- Время обработки изображения: ~50-200 мс
- Поддержка одновременных запросов: Flask (однопоточный по умолчанию)

Для продакшн-использования рекомендуется использовать WSGI-сервер (например, Gunicorn):

```bash
pip install gunicorn
gunicorn -w 4 -b 0.0.0.0:5000 app:app
```
