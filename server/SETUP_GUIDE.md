## Установка Python сервера

### 1. Требования

- Python 3.8 или выше
- pip (устанавливается вместе с Python)
- Обученная модель в формате H5 (уже есть в проекте: `2/numbers.h5`)

### 2. Установка зависимостей

Перейдите в корневую директорию проекта и установите зависимости:

```bash
cd /Users/vadvergasov/workspace/ML
pip install -r requirements.txt
```

Основные зависимости:
- `flask==3.0.0` - веб-фреймворк
- `flask-cors==4.0.0` - поддержка CORS
- `keras==3.12.0` - библиотека глубокого обучения
- `tensorflow==2.20.0` - библиотека машинного обучения
- `pillow==12.0.0` - обработка изображений
- `numpy==2.2.6` - работа с массивами

### 3. Проверка установки

Проверьте, что все зависимости установлены корректно:

```bash
python -c "import flask; import keras; import tensorflow; print('Все зависимости установлены успешно')"
```

## Запуск Python сервера

### 1. Базовый запуск

Перейдите в директорию сервера и запустите его:

```bash
cd server
python app.py
```

Сервер запустится на `http://0.0.0.0:5000`

### 2. Запуск с настройками окружения

Вы можете настроить сервер через переменные окружения:

```bash
export SERVER_HOST=0.0.0.0
export SERVER_PORT=5000
export DEBUG=False
python app.py
```

### 3. Проверка работоспособности

Откройте браузер или используйте curl для проверки:

```bash
curl http://localhost:5000/health
```

Ожидаемый ответ:
```json
{
  "status": "healthy",
  "model": {
    "input_shape": [null, 28, 28, 1],
    "output_shape": [null, 10],
    "num_params": 12345,
    "model_path": "../2/numbers.h5"
  }
}
```

### 4. Получение IP-адреса сервера

Для подключения iOS приложения вам понадобится IP-адрес вашего ноутбука:

**macOS:**
```bash
ipconfig getifaddr en0
```

**Linux:**
```bash
ip addr show | grep inet
```

**Windows:**
```cmd
ipconfig
```

## Настройка iOS приложения

### 1. Требования

- macOS с Xcode 14.0 или выше
- iOS устройство с iOS 15.0+ или симулятор
- Apple Developer Account (для запуска на реальном устройстве)

### 2. Открытие проекта

1. Откройте Xcode
2. Выберите "File → Open"
3. Перейдите в директорию `DigitRecognition`
4. Создайте новый проект или импортируйте существующие файлы

### 3. Настройка URL сервера

Откройте файл `DigitRecognition/Services/APIClient.swift` и замените `YOUR_SERVER_IP` на IP-адрес вашего ноутбука:

```swift
private init() {
    // Замените на IP-адрес вашего ноутбука
    self.baseURL = "http://192.168.1.100:5000"  // Ваш IP
    
    let configuration = URLSessionConfiguration.default
    configuration.timeoutIntervalForRequest = 30
    configuration.timeoutIntervalForResource = 60
    self.session = URLSession(configuration: configuration)
}
```

Или используйте поле ввода URL непосредственно в приложении.

### 4. Добавление разрешений

Откройте `Info.plist` и добавьте следующие разрешения:

```xml
<key>NSCameraUsageDescription</key>
<string>Приложению нужен доступ к камере для фотографирования цифр</string>
<key>NSPhotoLibraryUsageDescription</key>
<string>Приложению нужен доступ к фото для выбора изображений</string>
<key>NSPhotoLibraryAddUsageDescription</key>
<string>Приложению нужно разрешение для сохранения фотографий</string>
```

### 5. Сборка и запуск

1. Выберите целевое устройство (iPhone/iPad или симулятор)
2. Нажмите кнопку "Run" (⌘R) или выберите "Product → Run"
3. Предоставьте разрешения при запросе

## Тестирование системы

### 1. Тестирование сервера с curl

```bash
# Создайте тестовое изображение или используйте существующее
curl -X POST \
  -F "image=@test_image.png" \
  http://localhost:5000/predict
```

Ожидаемый ответ:
```json
{
  "success": true,
  "predictions": [0.01, 0.02, 0.85, 0.05, 0.02, 0.01, 0.01, 0.01, 0.01, 0.01],
  "predicted_class": 2,
  "confidence": 0.85
}
```

### 2. Тестирование с Python скриптом

Создайте тестовый скрипт `test_server.py`:

```python
import requests

url = "http://localhost:5000/predict"
with open("test_image.png", "rb") as f:
    files = {"image": f}
    response = requests.post(url, files=files)
    result = response.json()
    print(f"Предсказанная цифра: {result['predicted_class']}")
    print(f"Уверенность: {result['confidence']:.2%}")
```

### 3. Тестирование iOS приложения

1. Запустите iOS приложение
2. Нажмите "Галерея" и выберите изображение с цифрой
3. Или нажмите "Камера" и сфотографируйте цифру
4. Нажмите "Распознать"
5. Просмотрите результаты на экране результатов

### 4. Проверка сетевого подключения

Убедитесь, что iOS устройство и ноутбук находятся в одной сети:

**На iOS устройстве:**

**На ноутбуке:**
- Проверьте IP-адрес и сеть

## Troubleshooting

### Проблемы с сервером

**Сервер не запускается:**
```bash
# Проверьте, что порт 5000 свободен
lsof -i :5000

# Если занят, используйте другой порт
export SERVER_PORT=5001
python app.py
```

**Ошибка импорта модулей:**
```bash
# Переустановите зависимости
pip install --upgrade -r requirements.txt
```

**Модель не найдена:**
```bash
# Проверьте путь к модели
ls -la ../2/numbers.h5

# Если модель в другом месте, обновите MODEL_PATH
export MODEL_PATH=/path/to/numbers.h5
```

### Проблемы с iOS приложением

**Не удается подключиться к серверу:**
1. Проверьте, что сервер запущен
2. Убедитесь, что IP-адрес правильный
3. Проверьте, что устройства в одной сети
4. Отключите VPN на iOS устройстве
5. Проверьте настройки брандмауэра на ноутбуке

**Нет доступа к камере/фото:**
1. Проверьте разрешения в настройках iOS
2. Убедитесь, что описания добавлены в Info.plist
3. Попробуйте переустановить приложение

**Ошибка при отправке изображения:**
1. Проверьте формат изображения (PNG)
2. Убедитесь, что размер изображения не слишком большой
3. Проверьте логи сервера

### Проблемы с сетью

**Устройства не видят друг друга:**
1. Проверьте, что оба устройства подключены к одной сети
2. Отключите VPN и прокси
3. Перезагрузите роутер
4. Попробуйте использовать ping для проверки подключения

**Брандмауэр блокирует подключения:**

**macOS:**
```bash
# Разрешите входящие подключения в Системные настройки → Безопасность
# Или добавьте правило в брандмауэр
sudo /usr/libexec/ApplicationFirewall/socketfilterfw --add /usr/bin/python3
```

**Linux:**
```bash
# Разрешите порт 5000
sudo ufw allow 5000
```

**Windows:**
```bash
# Добавьте правило в брандмауэр Windows
netsh advfirewall firewall add rule name="Python Server" dir=in action=allow protocol=TCP localport=5000
```

// Сжатие перед отправкой
